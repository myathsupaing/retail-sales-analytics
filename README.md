# Retail Sales & Commercial Performance Analytics

An end-to-end data analytics project using dbt Core, Google BigQuery and SQL to explore retail sales performance and support data-driven business decisions.

## Project Objectives

- Analyse product and category sales performance.
- Evaluate store-level performance.
- Identify monthly sales trends and seasonality.
- Understand customer purchasing behaviour.
- Explore opportunities for improved inventory planning.

## Tools and Technologies

- SQL
- Google BigQuery
- dbt Core
- Power BI (planned)

## Project Scope

The project transforms raw retail transaction data into structured analytical models, validates data quality and develops business-focused insights.
